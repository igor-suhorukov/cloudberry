# parallel scan.  A path compiles from the port's copy under pg19/pax/src
# where there is one, and from Cloudberry's tree otherwise (meson.build).

# access/pax_vexec_source.cc, PAX's batch reader for vexec
# (pg_vector_executor.md §3.5.3), and access/pax_vexec_sink.cc, its batch
# sink (§3.16).
#
# Not here: storage/orc/orc_dump_reader.cpp and storage/micro_partition_udf.cc,
# the dump_pax_file_* functions, which print through tabulate, a git
# submodule of Cloudberry's: meson.build adds them where tabulate's headers
